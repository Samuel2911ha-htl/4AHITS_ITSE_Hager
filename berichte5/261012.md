# Wiederholung PHP

## Übung 2.1 (PHP)

**PHP Cheat Sheet**

1. Grundsyntax & Kommentare

Der PHP-Code wird gekennzeichnet mit Anfangs `<?php` und endet mit `?>`. Die Datei endet mit `-php`.
```php
<?php
// Dies ist ein einzeiliger Kommentar
# Dies ist ebenfalls ein einzeiliger Kommentar
/* 
Dies ist ein 
mehrzeiliger Kommentar 
*/
echo "Hallo Welt!"; // Ausgabe von Text
?>
```

2. Variablen

Variablen beginnen immer mit einem `$`. Der Datentyp wird automatisch erkannt. Ausgabe erfolgt ebenfalls mit dem Dollarzeichen.

$txt = "Hallo";        // String
$x = 5;                // Integer 
$y = 10.5;             // Float
$is_true = true;       // Boolean
$cars = array("VW");   // Array
$n = null;             // NULL

echo "$txt Welt";

var_dump(5);          // Ermittelt den Datentyp und gibt ihn zurück
var_dump("John");

3. Ausgabe (Echo & Print)

echo hat keinen Rückgabewert und kann mehrere Parameter aufnehmen. print hat den Rückgabewert 1 und kann nur einen Parameter aufnehmen. echo ist minimal schneller.

echo "Text ", "mehr Text"; 
print "Nur ein Text";


4. Strings (Zeichenketten)

Wichtige Funktionen zur Manipulation von Strings. Zeichenketten werden mit einem Punkt . verbunden.

$a = "Hallo";
$b = "Welt";
$c = $a . " " . $b; // "Hallo Welt"

strlen("Hallo");           // Gibt die Länge zurück: 5
str_word_count("Hallo");   // Zählt die Wörter: 1
strpos("Hallo Welt", "W"); // Sucht ein Zeichen/Wort, gibt Position zurück: 6
str_replace("Welt", "PHP", "Hallo Welt"); // Ersetzt Text: "Hallo PHP"
strtolower("HALLO");       // "hallo"
strtoupper("hallo");       // "HALLO"


5. Operatoren

Arithmetisch: +, -, *, /, % (Modulo), ** (Potenz)

Zuweisung: =, +=, -=, *=, /=

Vergleich: == (gleich), === (identisch: gleicher Wert & Typ), != oder <> (ungleich), !==, >, <, >=, <=

Logisch: and (&&), or (||), xor, ! (not)

6. Kontrollstrukturen (If...Else & Switch)

If / Elseif / Else

$t = 14;
if ($t < 10) {
  echo "Guten Morgen";
} elseif ($t < 20) {
  echo "Guten Tag";
} else {
  echo "Guten Abend";
}


Switch

$color = "rot";
switch ($color) {
  case "rot":
    echo "Farbe ist rot";
    break;
  case "blau":
    echo "Farbe ist blau";
    break;
  default:
    echo "Keine bekannte Farbe";
}


Match (ab PHP 8.0 - modernere Alternative zu Switch)

$result = match($color) {
    'rot' => 'Farbe ist rot',
    'blau' => 'Farbe ist blau',
    default => 'Keine bekannte Farbe',
};


7. Schleifen (Loops)

While & Do-While

$i = 1;
while($i <= 5) {
  echo $i;
  $i++;
}

// Do-While wird mindestens einmal ausgeführt
$j = 1;
do {
  echo $j;
  $j++;
} while ($j <= 5);


For & Foreach

for ($x = 0; $x <= 10; $x++) {
  echo "Nummer: $x <br>";
}

// Foreach ist ideal für Arrays
$colors = ["rot", "grün", "blau"]; // Kurze Array-Syntax
foreach ($colors as $value) {
  echo "$value <br>";
}


8. Funktionen

Code-Blöcke, die mehrfach verwendet werden können.

// Funktion mit Parameter und Default-Wert
function greet($name = "Gast") {
  return "Hallo " . $name;
}

echo greet("Anna"); // Ausgabe: Hallo Anna
echo greet();       // Ausgabe: Hallo Gast


9. Arrays

PHP kennt indizierte Arrays, assoziative Arrays und mehrdimensionale Arrays.

Indizierte Arrays

$cars = array("Volvo", "BMW", "Toyota");
// Ab PHP 5.4 auch: $cars = ["Volvo", "BMW", "Toyota"];
echo $cars[0]; // Ausgabe: Volvo
count($cars);  // Zählt die Elemente: 3


Assoziative Arrays (Schlüssel-Wert-Paare)

$age = ["Peter" => "35", "Ben" => "37", "Joe" => "43"];
echo "Peter ist " . $age['Peter'] . " Jahre alt.";

// Iterieren durch ein assoziatives Array
foreach($age as $name => $years) {
  echo "$name ist $years alt.";
}


Array Funktionen (Auswahl)

sort($array) - Aufsteigend sortieren

rsort($array) - Absteigend sortieren

asort($array) / ksort($array) - Assoziative Arrays nach Wert / Schlüssel sortieren

in_array("Wert", $array) - Prüft, ob ein Wert existiert

array_push($array, "Neu") - Fügt Element ans Ende an

10. Superglobals

Vordefinierte Variablen in PHP, die immer und überall zugänglich sind.

$_GET: Sammelt Formulardaten nach Absenden eines HTML-Formulars mit method="get". (Auch Daten aus der URL).

$_POST: Sammelt Formulardaten nach Absenden eines HTML-Formulars mit method="post".

$_SERVER: Enthält Informationen über Header, Pfade und Skript-Speicherorte (z.B. $_SERVER['PHP_SELF']).

$_SESSION: Speichert Session-Variablen für den aktuellen Benutzer.

$_COOKIE: Speichert Cookie-Werte.

11. Datum und Uhrzeit

echo date("Y-m-d H:i:s"); // Gibt z.B. 2026-10-12 14:30:00 aus
// Y = Jahr (4-stellig), m = Monat, d = Tag, H = Stunde (24h), i = Minuten, s = Sekunden


12. Include & Require

Zum Einbinden anderer PHP-Dateien. Der Unterschied: require erzeugt einen fatalen Fehler (Skript stoppt), wenn die Datei fehlt. include wirft nur eine Warnung (Skript läuft weiter).

include 'menu.php';
require 'database.php';


13. Formularverarbeitung (Sicherheit)

Wenn Daten via $_POST oder $_GET kommen, sollten sie zur Sicherheit bereinigt werden (Verhinderung von XSS-Attacken).

$name = htmlspecialchars($_POST["name"]); 
// Wandelt spezielle Zeichen (wie < und >) in HTML-Entitäten um


14. Sessions & Cookies

Sessions

Müssen zwingend vor jeglichem HTML-Output gestartet werden!

session_start();
$_SESSION["username"] = "admin";
echo $_SESSION["username"];
session_destroy(); // Session beenden


Cookies

// Name, Wert, Ablaufdatum (hier in 30 Tagen), Pfad
setcookie("user", "Alex", time() + (86400 * 30), "/"); 


15. Objektorientiertes PHP (OOP - Basics)

class Car {
  public $color; // Eigenschaft
  
  // Konstruktor
  public function __construct($color) {
    $this->color =$color;
  }
  
  // Methode
  public function message() {
    return "Mein Auto ist " . $this->color;
  }
}

$myCar = new Car("rot"); // Objekt instanziieren
echo $myCar->message();
