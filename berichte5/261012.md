## Übung 2.1 (PHP)

### PHP Cheat Sheet

1. Grundsyntax & Kommentare

Der PHP-Code wird gekennzeichnet mit Anfangs `<?php` und endet mit `?>`. Die Datei endet mit `-php`.
```php
<?php
// Dies ist ein einzeiliger Kommentar
# Dies ist ebenfalls ein einzeiliger Kommentar
/* 
Dies ist ein 
mehrzeiliger Kommentar 
*/
echo "Hallo Welt!"; // Ausgabe von Text
?>
```

2. Variablen

Variablen beginnen immer mit einem `$`. Der Datentyp wird automatisch erkannt. Ausgabe erfolgt ebenfalls mit dem Dollarzeichen.

$txt = "Hallo";        // String
$x = 5;                // Integer 
$y = 10.5;             // Float
$is_true = true;       // Boolean
$cars = array("VW");   // Array
$n = null;             // NULL

echo "$txt Welt";

var_dump(5);          // Ermittelt den Datentyp und gibt ihn zurück
var_dump("John");

3. Ausgabe (Echo & Print)

echo hat keinen Rückgabewert und kann mehrere Parameter aufnehmen. print hat den Rückgabewert 1 und kann nur einen Parameter aufnehmen. echo ist minimal schneller.

```php
echo "Text ", "mehr Text"; 
print "Nur ein Text";
```

4. Strings

Wichtige Funktionen zur Manipulation von Strings. Zeichenketten werden mit einem Punkt . verbunden.

```php
$txt = "Hallo Welt"
strlen("Hallo");           // Gibt die Länge zurück: 5
str_word_count("$txt");    // Zählt die Wörter: 2
strpos($txt, "W");         // Sucht ein Zeichen/Wort, gibt Position zurück: 6
str_contains($txt, "Welt");      // anstatt strpos ab PHP 8.0 oder später. Gibt allerdings nur "true" und "false" zurück
str_starts_with($txt, "Hallo");  // Prüft ob der String mit einem Zeichen oder Wort beginnt
str_end_with($txt, "Welt");  // Prüft ob der String mit einem bestimmten Zeichen oder Wort endet
str_replace("Welt", "PHP", "Hallo Welt"); // Ersetzt Text: "Hallo PHP"
strtolower("HALLO");       // "hallo"
strtoupper("hallo");       // "HALLO"
strrev($txt)    // Dreht einen String um
trim($txt)      // Entfernt Leerzeichen vor und nach dem Text

$a = "Hallo";
$b = "Welt";
$c = $a . " " . $b; // "Hallo Welt"
```

5. Operatoren

Arithmetisch: +, -, *, /, % (Modulo), ** (Potenz)

Zuweisung: =, +=, -=, *=, /=

Vergleich: == (gleich), === (identisch: gleicher Wert & Typ), != oder <> (ungleich), !==, >, <, >=, <=

Logisch: and (&&), or (||), xor, ! (not)

6. Kontrollstrukturen

If und elseif
```php
$t = 14;
if ($t < 10) {
  echo "Guten Morgen";
} elseif ($t < 20) {
  echo "Guten Tag";
} else {
  echo "Guten Abend";
}
```

Switch
```php
$color = "rot";
switch ($color) {
  case "rot":
    echo "Farbe ist rot";
    break;
  case "blau":
    echo "Farbe ist blau";
    break;
  default:
    echo "Keine bekannte Farbe";
}
```

Match (ab PHP 8.0 - modernere Alternative zu Switch)
```php
$result = match($color) {
    'rot' => 'Farbe ist rot',
    'blau' => 'Farbe ist blau',
    default => 'Keine bekannte Farbe',
};
```

7. Schleifen (Loops)

While

```php
$i = 1;
while($i <= 5) {
  echo $i;
  $i++;
}
```
Break Statement
um eine Schleife frühzeitig zu beenden
```php
$i = 1;
while($i <= 5) {
  if ($i == 3) break;
  echo $i;
  $i++;
}
```

Do-While

Mindestens 1mal ausgeführt bis die Bedingung erfüllt ist
```php
$i = 1;

do {
  echo $i;
  $i++;
} while ($i < 6);
```

For
```php
for ($x = 0; $x <= 10; $x++) {
  echo "The number is: $x <br>";
}
```

Foreach

Für geindexte Arrays
```php
$colors = array("red", "green", "blue", "yellow");

foreach ($colors as $value) {
  echo "$value <br>";
}
```

8. Funktionen

Erstellen
```php
function myMessage() {
  echo "Hello world!";
}
```

Aufrufen
```php
function myMessage() {
  echo "Hello world!";
}

myMessage();
```

Parameter
```php
function familyName($fname) {
  echo "$fname Refsnes.<br>";
}

familyName("Jani");
familyName("Hege");
familyName("Stale");
familyName("Kai Jim");
familyName("Borge");
```

Default Parameter
```php
function setHeight($height = 50) {
  echo "The height is : $height <br>";
}

setHeight(350);
setHeight(); // will take the default value of 50
```

9. Arrays

Arten:
Indexed arrays - Mit Index
Associative arrays - Mit benannten Schlüsseln
Multidimensional arrays - Enthalten ein oder mehr Arrays

```php
$cars = array("Volvo", "BMW", "Toyota");
```

Array Items
```php
$myArr = array("Volvo", 15, ["apples", "bananas"]);
```
Array Funktionen
```php
$cars = array("Volvo", "BMW", "Toyota");
echo count($cars);
```

Auf  ein Array Element zugreifen
```php
$cars = array("Volvo", "BMW", "Toyota");
echo $cars[0];
```

Ein Element verändern
```php
$cars = array("Volvo", "BMW", "Toyota");
$cars[1] = "Ford";
var_dump($cars);
```
